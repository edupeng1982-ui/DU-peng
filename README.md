# 实验记录本 Enote

Enote 是一款完全离线的 Windows 实验记录与生产事项管理工具。数据和图片只保存在使用者自己的电脑中，不需要注册、登录或联网。

## 下载与安装

请前往仓库的 [Releases](../../releases/latest) 页面，下载 `Enote-Setup-1.5.2.exe`。

系统要求：64 位 Windows 10 或 Windows 11。

> 安装包尚未使用商业代码签名证书签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。

## 主要功能

- 每条事件可粘贴、拖入或选择多张图片。
- 普通事件按日期从新到旧排列，支持搜索与完成状态。
- 当天未完成事件可自动顺延到下一天。
- 支持独立项目甘特图，可将大项目拆分为多个事件节点。
- 事件可标注为“实验”或“生产”。
- 生产事件可记录客户名称、单价和数量，并自动计算金额。
- 支持客户月度、年度销售额报表与折线图。
- 每月按客户生成对账单，可打印或另存为 PDF。
- 支持导出和导入完整本地备份。
- 普通事件及甘特图节点均可删除，删除事件时会同步清理关联图片。

## 数据与隐私

- 所有正式数据默认保存在 `%APPDATA%\实验记录本`。
- Enote 不上传事件、图片、客户信息或报表。
- 应用运行时会阻止 HTTP/HTTPS 网络请求。
- 本仓库不包含开发者或任何使用者的实验记录、图片和客户数据。

详细说明请查看 [PRIVACY.md](PRIVACY.md)。
